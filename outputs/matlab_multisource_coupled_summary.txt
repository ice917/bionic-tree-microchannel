Notes:
 * Static-tree reference numbers are recorded outputs of
   outputs/multi_source_results.csv ("3 chips, triangle | budget 600"), not recomputed here.
 * Pinned counts differ between coupled and static only if the two trees
   occupy different numbers of chip-block cells (exemption rule identical).
 * Single-source summary/scan radius columns came from an older inline stats
   script; this run uses the radius.py scheme (Python canonical) throughout.
 * Edge indices are MATLAB-linear-1 (i = y + x*grid); bbox/centroid are decoded
   accordingly. The recorded single-source summary/scan files used the
   transposed decode (their bbox_x/bbox_y and cx/cy equal our bbox_y/bbox_x
   and cy/cx). The cell set is identical -- only the axis labels swap, which
   is unobservable for the centred single source but was fixed here for the
   asymmetric 3-chip layout (chip-distance correctness was verified against
   a direct block-membership check).
