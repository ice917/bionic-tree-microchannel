Physarum adaptive-network routing (MATLAB)
==========================================

Model    : Bonifaci-Mehlhorn-Varma, "Physarum Can Compute Shortest
           Paths", arXiv:1106.0423, JTB 309:121-133, eq.(1)-(2).
           R_e = L_e/D_e, conductance C_e = D_e/L_e, dD_e/dt = |Q_e| - D_e,
           Q_e = C_e |p_u - p_v|, node eq. L p = b with
           L = diag(rowsum(A)) - A,  A = W + W.'.
Scheme   : Straszak-Vishnoi arXiv:1601.02712 eq.(12),
           D^{k+1} = (1-h) D^k + h |Q^k|, h in (0,1).  Keeps D>0 and
           makes ||D||_1 non-increasing (Lemma 5.6).
Post-proc: threshold D>thresh, then Prim MST on the saved network.
           Required because multi-source/single-sink is only a
           transportation problem: BMV Thm 7 gives attraction to the
           equilibrium SET only, Thm 8 needs "no two equilibria with
           equal cost"; Sun 2019 (arXiv:1903.08926) states the
           multi-source solver saved network is not guaranteed to
           be a tree nor connected, hence the MST pass.
Scope    : empirical demonstration only.  BMV leave approximate
           Steiner-tree computation as an open problem with "no
           theoretical analysis available", so nothing here is a
           certified optimum.
